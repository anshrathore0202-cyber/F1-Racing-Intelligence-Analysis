🏎️ F1 Racing Intelligence Analysis
Data Analytics | Tableau Dashboards | Interactive Web Application
📌 Project Overview

F1 Racing Intelligence Analysis is a data-driven project designed to explore, analyze, and visualize Formula 1 racing statistics and performance insights.

The project transforms raw Formula 1 data into meaningful insights through interactive Tableau dashboards and a dedicated website. It provides an analytical view of racing performance, driver achievements, constructor statistics, race results, and historical trends.

The main goal is to make Formula 1 data easier to understand through effective data visualization and interactive analytics.

🎯 Project Objectives
Analyze Formula 1 race data and historical performance.
Explore driver and constructor statistics.
Identify performance trends across different seasons.
Compare driver and team achievements.
Visualize racing insights through interactive Tableau dashboards.
Present analytical findings through a user-friendly website.
📊 Key Features
Driver Performance Analysis: Explore driver statistics, race wins, podium finishes, and championship performance.
Constructor Analysis: Compare team performance and achievements across seasons.
Race Analysis: Understand race results, finishing positions, and historical racing trends.
Data Visualization: Present complex racing data through interactive charts and dashboards.
Interactive Website: Provide a centralized platform to explore the project and its analytical insights.
Data-Driven Insights: Convert raw racing statistics into meaningful visual information.

⚙️ Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

bash
git clone https://github.com/anshrathore0202-cyber/F1-Racing-Intelligence-Analysis.git


2. Navigate to the project directory

bash
cd F1-Racing-Intelligence-Analysis


3. Create a virtual environment

bash
python -m venv venv


4. Activate the virtual environment

Windows:

bash
venv\Scripts\activate


5. Install the required dependencies

bash
pip install -r requirements.txt


6. Run the application

If your project uses Flask and the entry point is app.py:

bash
python app.py


Open the local URL displayed in your terminal to access the website.
